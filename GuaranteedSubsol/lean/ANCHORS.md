# Frozen anchors — GuaranteedSubsolutions

Author-approved theorem statements. Each lives alone in its file under
`LeanHJBAutoformalisation/GuaranteedSubsol/Anchors/`. A frozen statement is never edited in place:
a defect requires an author ruling and a versioned successor. Only the proof body may change, to
`by exact <provider>` once a provider exists.

`DRAFT_SORRY` anchors are not proved, and must not be imported by production code (they are not
imported by the root file `LeanHJBAutoformalisation.lean`). Build them explicitly with
`lake build LeanHJBAutoformalisation.GuaranteedSubsol.Anchors.<Name>`. Sealed anchors are imported
by the root file.

axioms standard, independent audit pending); `PROVED` (sealed and audited).

Conventions. The Kruzkov operator `kruzkovOp α Λ` takes the timescale `α` (it applies
`kruzkov (1/α)` internally); the Kruzkov transform `kruzkov αinv` takes the inverse timescale.
Statements that involve both `kruzkovOp` and explicit exponentials or transforms (`t_advances`,
`t_advances_withUnknown`, the two implications of `prop:subadd_local`) use both `α` and `αinv`
with the hypothesis `α * αinv = 1`; statements involving only `kruzkovOp` use `α` alone; statements
involving only `kruzkov` or exponentials (`le_mul_iff_kruzkov`, `kruzkov_mul_eq_neg_rpow`, the
rescalings `local_iff_local_x` and `local_iff_local_x_sq`) use `αinv` alone.
